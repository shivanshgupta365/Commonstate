# 90-second guided demo

The same six-step proof is interactive inside `/tano`.

**0–10s — Frame the problem**

“Agents do not need every document. They need the right current state, and
humans need to know why they acted.” Point to the five-of-many context pack.

**10–25s — Ask**

Run the launch-readiness question. Show Amara Okafor and Imani Brooks as
eligible, Jo Park held, literal source spans, and public-versus-synthetic labels.

**25–45s — Change the truth**

Ingest the prepared synthetic Slack update. Review all extracted proposals,
their conflicts, and the blast radius. Approve and propagate the new truth.

**45–65s — Run the agent**

Run the Relationship Agent. Inspect the returned action/hold split, provider,
context hash, approvals, and the receipt bound to exact evidence.

**65–80s — Replay**

Replay the prior run against current state. Show a formerly valid action now
blocked because critical truth changed.

**80–90s — Close the loop**

Record the outcome. The new learning enters the Change Inbox as a proposal; it
cannot approve itself. Close with: “Every human. Every agent. Same state.”
